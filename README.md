# Personal Greeting Website

A small static website project built as a personalized birthday greeting page, using HTML, CSS, and JavaScript.

## Files

- `index.html` — greeting page and content
- `styles.css` — visual styling
- `script.js` — page interactions
- `favicon.svg` and `social-preview.svg` — browser and sharing graphics

## Run Locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Privacy and Media Notes

- This is a personal greeting project, not a professional portfolio project.
- Before keeping this repository public, confirm the named recipient is comfortable with the page being publicly accessible. Consider making the repository private if it is intended only for one person.
- Use only audio and images you created, licensed, or have permission to distribute. A music file being available online does not mean it can be redistributed in a public repository.
- Avoid including private messages, phone numbers, addresses, or other personal details.
