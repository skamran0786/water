# A Message for Nisha

A small static website built with HTML, CSS, and JavaScript to communicate a sincere apology and clarify that the relationship was understood as friendship only.

## Files

- `index.html` — message page and content
- `styles.css` — visual styling
- `script.js` — page interactions
- `favicon.svg` and `social-preview.svg` — browser and sharing graphics

## Run Locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Privacy

This is a personal message. Consider making the repository private if it is intended only for its recipient. Avoid adding private photos, contact details, or other personal information without permission.
